# 学习路线入口

先完成 Java 基础、并发和 JVM，再按项目根目录 README 的顺序进入 Spring、Web、数据库、缓存、消息和微服务。POM 中预先声明的技术依赖只是学习准备；中间件仍需按专题单独配置和运行。

## 学习记录建议

每个主题在 `docs/notes/` 新建一份笔记，记录：问题、自己的解释、最小代码、观察结果、仍不确定的点、下一步验证。实验代码集中放在 `com.example.learning.lab` 的对应子包，并附实验 README。

当前实验：[未同步计数器](lab/concurrency/README.md)。

中间件与框架专题目录：[后端技术栈专题目录](stack/README.md)。
