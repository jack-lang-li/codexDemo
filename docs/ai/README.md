# AI 辅助学习规范

AI 用于提问、审查和比较方案，学习者负责先形成自己的理解、实现和结论。不要把生成的代码当作已经理解或已经验证的代码。

建议流程：

1. 先查资料、复现问题，并写下自己的解释和方案。
2. 让 AI 通过问题帮助检查理解，或仅审查自己写的代码。
3. 要求反馈指向具体的概念、风险和验证方法；先自己修改。
4. 自己运行测试/实验，区分实测结果与推断。
5. 在笔记中记录原先的想法、实际观察和最终结论。

需要 AI 起草代码时，限定一个小范围，要求解释设计选择、指出尚未验证之处，并逐段阅读后再采纳。AI 生成的测试也需要自己检查覆盖范围和断言理由。
